# EplanMcp

[![Русский](https://img.shields.io/badge/Документация-Русский-2374C8?style=for-the-badge)](README.md) [![English](https://img.shields.io/badge/Documentation-English-555555?style=for-the-badge)](README.en.md) [![中文](https://img.shields.io/badge/文档-简体中文-D97706?style=for-the-badge)](README.zh-CN.md)


**Управление EPLAN с помощью естественного языка.** EplanMcp — сервер [Model Context Protocol](https://modelcontextprotocol.io/), позволяющий AI-клиентам, включая Claude Code, читать и изменять проекты EPLAN Electric P8 / Pro Panel через .NET API: запрашивать данные, создавать схемы, размещать оборудование, обновлять отчёты и экспортировать чертежи.

Управление изменениями остаётся за инженером: по умолчанию операции записи выполняются в режиме предварительного просмотра, изменения реальных проектов требуют подтверждения, действия журналируются и поддерживают механизмы отмены.

![Пример схемы, созданной через MCP](docs/images/readme-demo.png)

*Страница цепи пуска двигателя создана вызовами MCP: создание страницы, размещение устройств (включая -Q1 из базы изделий), автоматическое соединение и экспорт изображения без ручного черчения.*

> **Статус:** предварительная версия 0.x для испытаний. Параметры и структуры результатов инструментов могут изменяться. См. [историю изменений](CHANGELOG.md) и [план развития](docs/roadmap.md).

## Примеры запросов

- «Сколько страниц в проекте и на каких расположен -K1?»
- «У каких двигателей не назначены изделия?»
- «К каким устройствам подключена нагрузочная сторона =GAA+A1-FC1?»
- «Создай страницу, вставь цепь и покажи полный перечень планируемых изменений».
- «Замени Motor на Drive в свободных текстах этих страниц, только для английского языка, сначала покажи предварительный результат».

## Преимущества по сравнению с генерацией произвольных скриптов

| Аспект | Произвольный скрипт LLM | EplanMcp |
|---|---|---|
| Вызов API | Модель может придумать несуществующий интерфейс | Фиксированные параметры, валидация, сведения из документации и [испытаний](docs/eplan/api-notes.md) |
| Проверка результата | Успешный ответ может не соответствовать изменению проекта | Повторное чтение, проверка и предупреждение либо откат |
| Область изменений | Скрипт может менять любые открытые проекты | Предварительный просмотр и подтверждение записи |
| Восстановление | Ручное восстановление | Отмена обычных изменений, резервирование перед разрушительными операциями |
| Прослеживаемость | Нет гарантированного журнала | Журнал вызовов с хеш-цепочкой |

## Быстрый старт

**Требования:** Windows 10/11 x64; EPLAN 2026 Electric P8 или Pro Panel с лицензией API Extension и разрешением на неподписанные дополнения; MCP-клиент.

1. Скачайте `EplanMcp-<version>.zip` и `SHA256SUMS.txt` из [Releases](https://github.com/asckye/eplan-mcp/releases). Проверьте контрольные суммы, разблокируйте ZIP и распакуйте в постоянный каталог, например `D:\\EplanMcp`.
2. Запустите `workbench\\EplanMcp.Workbench.exe`, зарегистрируйте дополнение для нужной версии EPLAN и настройте клиент.
3. Откройте проект в EPLAN и запросите перечень страниц.

Установка не требует прав администратора. Дополнительные сведения: [руководство на китайском](docs/getting-started/zh-CN.md), [английское руководство](docs/getting-started/en.md).

## Архитектура

- **Host** (`eplanmcp.exe`, .NET 10): stdio MCP, инструменты, политики, подтверждения, аудит.
- **EPLAN Bridge** (.NET Framework 4.8.1): дополнение EPLAN, вызывающее API в главном потоке; обмен с Host через именованный канал, доступный текущему пользователю.
- **Workbench**: регистрация дополнения, настройка клиента и подтверждение операций.

Подробности: [архитектура](docs/architecture/architecture.md), [ADR](docs/adr/README.md).

## Безопасность

- **Предварительный просмотр:** при отсутствии `dry_run` инструменты записи возвращают план без изменения проекта ([ADR-0049](docs/adr/0049-write-tools-preview-by-default.md)).
- **Подтверждение:** в тестовых проектах обычные записи могут разрешаться автоматически; в реальных проектах требуется подтверждение через Workbench или EPLAN ([ADR-0005](docs/adr/0005-safety-model.md), [ADR-0011](docs/adr/0011-approval-out-of-band.md)).
- **Резервирование:** разрушительные операции требуют подтверждения и резервной копии, включая тестовые проекты. При ошибке резервирования операция не выполняется ([ADR-0013](docs/adr/0013-destructive-backup.md)).
- **Аудит:** действия заносятся в журнал с хеш-цепочкой. При неопределённом результате записи блокируются до проверки инженером ([ADR-0010](docs/adr/0010-write-outcomes.md)).

## Ограничения

- Проверенная версия — EPLAN 2026.0.3. Версии 2024, 2025 и 2027 пока не проверены; 2022 и 2023 не поддерживаются.
- Дополнение в версии 0.x поставляется без цифровой подписи.
- Полная реконструкция небольшого проекта по образцу ещё проходит приёмку. Создание 3D-компоновок Pro Panel не поддерживается.
- AI может ошибаться: проверяйте планы изменений и сначала работайте с тестовыми проектами.
- Данные проекта, возвращаемые инструментами, могут передаваться AI-клиентом внешнему поставщику модели. Перед работой с конфиденциальными проектами проверьте политику передачи данных. Локальная установка и соединение EplanMcp не требуют интернета.

## Разработка из исходников

```powershell
dotnet build src\EplanMcp.Host -c Release
dotnet build src\EplanMcp.Bridge.Eplan -c Release
eng\scripts\eplan-addin.ps1 -Action register -Variant 'Electric P8'
src\EplanMcp.Host\bin\Release\net10.0\eplanmcp.exe doctor
```

Добавление в Claude Code (замените путь к репозиторию):

```powershell
claude mcp add -s user eplan -- "<путь-к-репозиторию>\src\EplanMcp.Host\bin\Release\net10.0\eplanmcp.exe" serve
```
